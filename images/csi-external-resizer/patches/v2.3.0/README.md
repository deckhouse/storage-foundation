# Patches

Applied to `kubernetes-csi/external-resizer` v2.3.0 (k8s 1.34 track) during build of the `csi-resizer` binary.

## 001-fix-cve.patch

Bumps `golang.org/x/net` `v0.58.0 -> v0.60.0` (CVE-2026-78669) and
`golang.org/x/text` `v0.41.0 -> v0.42.0` (CVE-2026-56851) to clear the findings
Trivy reports against the upstream `go.mod` of v2.3.0; `golang.org/x/crypto` `v0.56.0 -> v0.57.0`, `golang.org/x/sys`,
`sync` and `term` move along with x/net.

Generated by cloning v2.3.0, running `go get golang.org/x/net@v0.60.0` and
`go mod tidy`; touches only `go.mod` / `go.sum` (the build re-runs
`go mod download` / `go mod vendor`).
