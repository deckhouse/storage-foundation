# Patches

Applied to `kubernetes-csi/node-driver-registrar` v2.18.0 during build of the `csi-node-driver-registrar` binary.

## 001-fix-cve.patch

Bumps `golang.org/x/net` `v0.58.0 -> v0.60.0` (CVE-2026-78669) and
`golang.org/x/text` `v0.41.0 -> v0.42.0` (CVE-2026-56851) to clear the findings
Trivy reports against the upstream `go.mod` of v2.18.0; `golang.org/x/sys`,
`sync` and `term` move along with x/net.

Generated by cloning v2.18.0, running `go get golang.org/x/net@v0.60.0` and
`go mod tidy`; touches only `go.mod` / `go.sum` (the build re-runs
`go mod download` / `go mod vendor`).

## 900-fix-cve-go-deps.patch

Generated by `fix_go_vulns.py` (deckhouse/storage/common) against `v2.18.0` on top of the other patches in this directory; regenerated on every run, do not edit by hand. When the upstream version changes, delete this patch or rerun the script (`fix_go_vulns.py --only <module>`): the old one will not apply to the new tag. - `go.mod`: `go.opentelemetry.io/otel` v1.46.0 → v1.47.0
- `go.mod`: `go.opentelemetry.io/otel/metric` v1.46.0 → v1.47.0
- `go.mod`: `go.opentelemetry.io/otel/trace` v1.46.0 → v1.47.0 (CVE-2026-128085)
- `go.mod`: `golang.org/x/net` v0.60.0 → v0.62.0 (CVE-2026-78661, CVE-2026-97045)
- `go.mod`: `golang.org/x/sys` v0.48.0 → v0.49.0
- `go.mod`: `golang.org/x/text` v0.42.0 → v0.43.0
