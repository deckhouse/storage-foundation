# Patches

Applied to `kubernetes-csi/external-attacher` v4.13.0 during build of
the `csi-attacher` binary.

## 001-fix-cve.patch

Bumps `golang.org/x/crypto` `v0.55.0 -> v0.57.0` (CVE-2026-56855,
CVE-2026-78662), `golang.org/x/net` -> `v0.60.0` (CVE-2026-78669) and `golang.org/x/text` -> `v0.42.0`
(CVE-2026-56851); x/net v0.60.0 also raises `golang.org/x/crypto` to `v0.57.0` and
`golang.org/x/sys` / `sync` / `term` along with it, to clear the
findings Trivy reports against the upstream `go.mod` of v4.13.0. The remaining
`golang.org/x/crypto` advisory GO-2026-5932 has no fixed release and is
covered by `../../known_vulnerabilities.vex`.

Generated by cloning v4.13.0, running `go get golang.org/x/crypto@v0.56.0`,
`go get golang.org/x/net@v0.60.0` and `go mod tidy`; touches only `go.mod` / `go.sum` (the build removes
`vendor/` and re-runs `go mod download` / `go mod vendor`).

## 900-fix-cve-go-deps.patch

Generated by `fix_go_vulns.py` (deckhouse/storage/common) against `v4.13.0` on top of the other patches in this directory; regenerated on every run, do not edit by hand. When the upstream version changes, delete this patch or rerun the script (`fix_go_vulns.py --only <module>`): the old one will not apply to the new tag.
