# Patches

Applied to `kubernetes-csi/external-attacher` v4.13.0 during build of
the `csi-attacher` binary.

## 001-fix-cve.patch

Bumps `golang.org/x/crypto` `v0.55.0 -> v0.56.0` (CVE-2026-56855,
CVE-2026-78662) to clear the findings Trivy reports against the upstream
`go.mod` of v4.13.0. No other module moves. The remaining
`golang.org/x/crypto` advisory GO-2026-5932 has no fixed release and is
covered by `../../known_vulnerabilities.vex`.

Generated by cloning v4.13.0, running `go get golang.org/x/crypto@v0.56.0`
and `go mod tidy`; touches only `go.mod` / `go.sum` (the build removes
`vendor/` and re-runs `go mod download` / `go mod vendor`).
