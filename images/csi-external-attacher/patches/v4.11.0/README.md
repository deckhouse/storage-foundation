# Patches

Applied to `kubernetes-csi/external-attacher` v4.11.0 during build of
the `csi-attacher` binary.

## 001-fix-cve.patch

Bumps direct/indirect dependencies in `go.mod` / `go.sum` to versions
that fix CVEs reported by Trivy:

- `google.golang.org/grpc` `v1.72.2 -> v1.80.0` (fixes CVE-2026-33186)
- `go.opentelemetry.io/otel` `v1.38.0 -> v1.43.0` (fixes CVE-2026-29181)
- `go.opentelemetry.io/otel/sdk` `v1.36.0 -> v1.43.0` (fixes
  CVE-2026-24051, CVE-2026-39883)
- `golang.org/x/crypto` `v0.45.0 -> v0.47.0`
- `google.golang.org/protobuf` `v1.36.8 -> v1.36.11`

The patch was generated by cloning v4.11.0, running
`go mod edit -require=...` for the three core modules above followed by
`go mod tidy -e` against `GOPROXY=proxy.golang.org`, then
`git format-patch -1`. It only modifies `go.mod` / `go.sum`; the build
pipeline does `rm -r vendor && go mod download` before `make build`,
so the new versions are pulled fresh from the module proxy. Verified
end-to-end inside `golang:1.25-alpine` with `go build -mod=readonly`.

## 002-fix-cve-golang-x.patch

Bumps `golang.org/x/net` -> `v0.56.0` (CVE-2026-46600) and
`golang.org/x/text` -> `v0.39.0` (CVE-2026-56852) in `go.mod` / `go.sum` to
clear the findings reported by Trivy; this also pulls the transitive
`golang.org/x/crypto` -> `v0.53.0`, `golang.org/x/sys` -> `v0.46.0`,
`golang.org/x/sync` -> `v0.21.0` and `golang.org/x/term` -> `v0.44.0` bumps. Generated by cloning
the pinned upstream version, applying the existing patches, then
`go get`/`go mod tidy` and `git format-patch -1`; touches only
`go.mod` / `go.sum` (the build re-runs `go mod vendor`/`download`).

## 003-fix-cve-grpc-cel-go.patch

Bumps `google.golang.org/grpc` -> `v1.82.1` (GHSA-hrxh-6v49-42gf, xDS RBAC
and HTTP/2 vulnerabilities) and `github.com/google/cel-go` -> `v0.29.0`
(GHSA-gcjh-h69q-9w9g, JSON private fields exposed via NativeTypes) to clear
the findings reported by Trivy on the built binary. Generated by cloning the
pinned upstream version, applying the earlier patches, then `go get` and
`go mod tidy`; touches only `go.mod` / `go.sum` (the build re-runs
`go mod download`/`go mod vendor`).

## 004-fix-cve-grpc-x-crypto.patch

Bumps `google.golang.org/grpc` -> **v1.83.2** (CVE-2026-84304 and
CVE-2026-84303, fixed in 1.83.1, and CVE-2026-84445, fixed in 1.83.2) and
`golang.org/x/crypto` -> **v0.57.0** (CVE-2026-56854, the x/crypto/ssh
source-address authentication bypass, plus CVE-2026-56855 and
CVE-2026-78662) to clear the findings Trivy reported against the built
`csi-attacher` binary. Generated by cloning the pinned upstream version, applying
the earlier patches, then `go get` and `go mod tidy`; touches only
`go.mod` / `go.sum` (the build re-runs `go mod download`/`go mod vendor`). The `go` directive moves to 1.26.0, the language version x/crypto v0.57.0 requires.

## 005-fix-cve-otel-1.45.patch

Bumps the six `go.opentelemetry.io/otel*` modules -> **v1.45.0** to clear
CVE-2026-81870, reported by Trivy against the built `csi-attacher` binary: the
OTLP trace exporters stood at v1.34.0 and the core, `metric`, `sdk` and
`trace` modules at v1.44.0. OpenTelemetry-Go releases the whole set together,
so all six move to the same tag. Generated by cloning the pinned upstream
version, applying the earlier patches, then `go mod edit` and `go mod tidy`;
touches only `go.mod` / `go.sum` (the build re-runs
`go mod download`/`go mod vendor`).
